# Dibble Dash Revival
this is a revival for the mobile game dibble dash, which died in 2023 with jumpstart (formerly knowledge adventure) shutting down, some of their games were revived but not this one, so I've chosen to put it on here!

# REQUIREMENTS
Python

ADB (included in the package so it's no problem)

pycryptodome or cryptography (either one installed with pip)

that's basically it (will be updated once i get all the requirements)

# required commands to run
dibble_server.py --port 8080 (any port will work as long as it's unused)

adb reverse tcp:8080 tcp:8080 (run this twice by pressing the up arrow key after pasting it in the first time)

# one last note
the server runs locally on your machine, right now, only Windows has been tested, so Linux and macOS support is not guaranteed unless someone tests it and makes an issue

there's also a missing - on the splash screen that i modified, so don't forget that!
